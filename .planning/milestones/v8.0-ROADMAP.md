## Overview

Replace the IntelDossier/Bureau prototype design language with a single **Linear-derived** visual direction — on properly-bridged shadcn/ui RTL infrastructure and HeroUI v3 (bumped 3.0.5 → 3.2.1), with Aceternity fully removed — while preserving Arabic RTL correctness on all four axes (dark/light × LTR/RTL) throughout.

**Verified scope reality (2026-07-02 pre-execution review):** smaller than a four-part migration. HeroUI was **already** on the v3 compound-component API; **none** of the "v3-removed" components (Navbar/Snippet/User/Spacer/Image/Code/Autocomplete/DateInput) were imported; the Latin fonts were **already** Inter + JetBrains Mono. The genuine work concentrated in the Linear palette re-skin (P77), the 8-component Aceternity rebuild (P79), and RTL direction-source consolidation (P76). Phase 78 reduced to a version bump + regression sweep.

**Hard sequencing (from research):** audit → RTL infrastructure bridge + shadcn logical properties → Linear tokens → HeroUI v3 API audit/bump → Aceternity removal → visual/a11y verification across all baselined surfaces. Visual baselines (VERIFY-01) were captured **before** the token phase ran (gating step of Phase 77) and re-compared in the final phase (Phase 80). The `bootstrap.js`/`directions.ts` byte-match CI guard (FOUC-01) was added at the **start** of Phase 77, before any token literal moved.

## Milestone Summary

**Delivered:** Retired the four-direction Bureau/Chancery/Situation/Ministerial design language (and the accent-hue axis) in favor of a single **Linear** visual direction — a re-skin of the existing OKLCH token engine, not a rebuild — on consolidated shadcn RTL infrastructure bridged into Radix, with HeroUI bumped 3.0.5 → 3.2.1 and Aceternity fully removed. Arabic RTL correctness preserved on all four axes (dark/light × LTR/RTL), proven by a full-route visual re-compare (human-approved, 0 regressions) + an honest recorded axe baseline + RTL portal/component smoke tests locked into CI.

**Key Decisions:**

- **Linear is the sole visual direction (no coexistence).** The four legacy directions and the Tweaks-drawer direction+hue switchers were fully retired; `Direction` type collapsed to `'linear'`; every persisted `id.dir` coerced to `linear` in a dual layer (`bootstrap.js` + `DesignProvider`) so no legacy profile loses first-paint tokens. Default theme is dark-canonical.
- **Re-skin, not rebuild.** Linear dark + derived-light token sets were transcribed from `.planning/research/STACK.md` (verbatim from shadcn.io/design/linear), NOT from the outgoing `frontend/DESIGN.md` Bureau spec, and wired through the existing `directions.ts`/`buildTokens.ts`/`applyTokens.ts` engine.
- **FOUC three-copy byte-match invariant extended to Linear.** `directions.ts` ↔ `bootstrap.js` ↔ `index.css :root` enforced by `check-bootstrap-parity` in lint + CI, with coercion probes.
- **Phase 78 is a bump + regression sweep, not a migration.** The Phase 75 audit confirmed the tree was already on the v3 compound API with none of the v3-removed components in use and Inter + JetBrains Mono already in place.
- **Aceternity was 1 live + 7 dead.** ACET-01 satisfied by rebuilding SearchableSelect on HeroUI v3/Radix (preserving the Phase 75 RHF/Zod/ARIA/keyboard contract) and deleting the 7 dead components.
- **Anti-laundering visual verification.** VERIFY-01 re-compared 43 baselines via a HUMAN blocking diff-triage before any baseline PNG was recaptured; recapture was a separate plan (80-05) gated on the human verdict.
- **RTL smokes ship advisory (green-from-birth).** The `test-rtl-smokes` CI job (name "RTL Portal + Component Smokes") uses DOM/computed-style assertions only; branch-protection promotion was deferred to repo-admin (honest deferral; confirmed NOT silently claimed among main's 8 required contexts).

**Issues Resolved:**

- Dark-mode accent WCAG-AA regression surfaced in the 77-GAPFIX code review — `accent.ink`-on-`accent.soft` 2.03 → 6.05:1, plus 69 `text-accent` body usages rerouted to an AA token.
- Linear-light `color-contrast` scans on the semantic status chips (`.chip-danger/-warn/-ok/-info`) — swapped ad-hoc `color-mix` washes for the AA-proven opaque `var(--*-soft)` tokens (light 5.00–5.37:1 / dark 4.73–7.76:1) without touching a palette literal.
- `calendar-rtl` seed cliff (2026-08-01) — defused with a constructor-only `Date` override (freezes no-arg `new Date()` → July 2026 while `Date.now()` stays real, so the Supabase storageState token is never seen as expired → no refresh storm → the SRTL-02 grid renders).

**Issues Deferred (non-blocking, recorded in the audit):**

- `test-rtl-smokes` branch-protection promotion — deferred pending repo-admin (job ships advisory).
- CI "birth certificate" (first green GitHub Actions run of the a11y + rtl-smokes jobs) — deferred to the v8.0 PR; main is local-only ahead, local green is the phase-exit proof.
- `calendar-rtl` green-from-birth requires the CI `E2E_ADMIN` account to equal the `kazahrani` organizer (organizer-scoped RLS on the SRTL-02 rows) — advisory contingency.
