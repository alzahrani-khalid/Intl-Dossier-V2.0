<objective>
Reshape `.github/workflows/ci.yml` so that the `main` run P101-07 observes can be green - the one plan
that touches `.github/workflows/*`.

Five decisions land in one file (RESEARCH §1.3, §7, §9 F1/F3):

- **D-01 Security Scan** (REQUIRED, red on every `main` push): `github/codeql-action/upload-sarif@v2` is
  deprecated and the job has no `security-events: write`. Fix: `@v3` plus a `permissions:` block on that
  job (`security-events: write`, `contents: read`, `actions: read`).
- **D-07 delete `test-e2e`**: turbo strips `TEST_USER_*` and, behind that, the bare frontend
  `playwright test` collects 0 tests with 10 load errors. It has never had a runnable suite. `e2e.yml`
  (220 tests, sharded, against the deployed app) is the E2E suite. Nothing `needs:` it.
- **D-08 Docker Build**: no root `Dockerfile` exists. The droplet builds `frontend`, `backend`,
  `agent-runtime` from their own `Dockerfile.prod`. The job becomes build-only (`push: false`) over those
  three, no login, no metadata action, still `push` to `main`/`develop` only - as THREE STEPS in ONE job
  named exactly `Docker Build`, because a matrix would rename the context to `Docker Build (frontend)`
  and silently shrink the six-job population D-14 hard-codes.
- **D-06 frontend Playwright steps** (`test-a11y`, `test-rtl-smokes`, `test-rtl-responsive`): invoke
  `node ../scripts/pw-run-reaped.mjs -- <args>` from `./frontend`. The wrapper appends `--reporter=json`
  and the last `--reporter` wins, so `--reporter=html` is dropped and the upload step's `path` becomes
  `frontend/test-results/` (the wrapper's published `pw-reaped-<nonce>.json` plus traces).
- **D-04 integration job**: command unchanged (`pnpm --filter intake-backend test:integration`),
  `continue-on-error: true` stays until a green run proves it can go.

Runtime job count on `main` goes 19 to 18 (the deleted E2E job); YAML job keys go 18 to 17 (`build` is a
two-way matrix, one key, two runtime jobs).
</objective>
