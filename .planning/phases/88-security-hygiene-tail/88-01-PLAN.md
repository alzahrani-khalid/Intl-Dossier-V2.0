Close SEC-01: `UserPicker.handleSearch` interpolates raw user input into a supabase-js `.or()` PostgREST logic-tree string with no escaping. Fix via PostgREST double-quoting of the whole `%...%` pattern (escape `\` and `"` inside), which is injection-proof AND preserves dot-in-email search. Purpose: PostgREST parses `,` `(` `)` `.` `:` as logic-tree syntax — input like `x,email.eq.` splices new filter conditions (T-79-S2 / IN-04). Quoting per PostgREST grammar makes the value literal.
Output: shared `quotePostgrestValue` helper, fixed UserPicker, 5 sibling one-line fixes, tests pinning the grammar.
</objective>
