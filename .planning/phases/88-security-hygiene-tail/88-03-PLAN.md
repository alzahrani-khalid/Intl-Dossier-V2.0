<objective>
Root-cause fix for the Express 5 `req.query` bug: `backend/src/utils/validation.ts:45` assigns `req.query = result as any`, but Express 5.2.1 defines `req.query` as a getter-only prototype property (`set: undefined`, verified against installed source at node_modules/express/lib/request.js:217). The assignment throws TypeError in strict mode, caught by the generic catch → 500 on every one of the 17 `validate({ query })` routes.

Purpose: availability — all validated-query list endpoints (after-action, countries, commitments, elected-officials, events, mous, organizations, permissions, positions, tasks, ...) currently 500.
Output: one `Object.defineProperty` shadow in the shared helper + a unit test pinning the semantics.
</objective>
