Current geometry (verified 2026-07-04):
- `.col` — `width: 300px; min-width: 300px; flex-shrink: 0` (board.css ~L101-113).
  4 × 300px + 3 × 12px gap = 1236px required.
- `.board-columns` — `display: flex; gap: 12px; overflow-x: auto` (board.css ~L261-268).
- `.workboard-page` — `max-width: 1400px; padding: var(--pad) 24px` (board.css ~L252-259),
  BUT `styles/list-pages.css:858` overrides it to `max-width: none; margin-inline: 0`
  under `.appshell-main`. The app shell sidebar is 256px, so content at a 1400px viewport
  is ~1144px minus 48px padding ≈ 1096px — less than the 1236px the columns need. That is
  the clip.
- `WorkBoard.tsx` renders `<div className="board-columns">` wrapping
  `KanbanProvider className="contents"` (display:contents — tailwind-merge drops the
  provider's own `grid` class), so `section.col` elements are direct flex children of
  `.board-columns`. The scroll container is `.board-columns`.
- `.appshell` has `overflow: hidden` (list-pages.css ~L845) — vertical page scroll happens
  inside `.appshell-main`; horizontal scroll must happen on `.board-columns` itself.
- Existing `@media (max-width: 640px)` block (board.css ~L316-336) sets snap +
  `width: min(300px, calc(100vw - 28px))` — must be preserved.
