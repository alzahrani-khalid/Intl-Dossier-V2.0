<objective>
Fix BUG-04 (F6, MEDIUM) and BUG-05 (F22, LOW) — both live on the dashboard widget surface
and share `i18n/{en,ar}/dashboard-widgets.json`.

BUG-04 is an i18n KEY GAP, not a render rewrite: `WeekAhead.tsx:163-164` already localizes
via `t('weekAhead.status.' + stage, { defaultValue: stage })`, but the loaded
`dashboard-widgets` namespace only defines scheduled/confirmed/pending/in_progress/completed/
cancelled — while the widget's `event.lifecycle_stage` is typed `LifecycleStage`
(intake | preparation | briefing | execution | follow_up | closed). All six real values are
missing, so raw snake_case enums (`preparation`, `follow_up`) leak through the defaultValue.

BUG-05: `.kpi-label` (10.5px base / 11px `.dir-linear`, uppercase, letter-spacing) wraps to
two lines at 1024px ("ACTIVE ENGAGEMENTS"; the AR "SLA at Risk" label is longest).

Output: six new status keys in EN + AR (labels aligned with the canonical
`i18n/{en,ar}/lifecycle.json` stage labels), a real-JSON coverage test, and a CSS-only
single-line rule for KPI labels at ≤1024.
</objective>
