## Decisions Made

- **Layout shape (a)**, as recorded above.
- **The wizard is gone, not re-gated.** UI-SPEC's contract is "grid, empty or not"; a wizard that only appears when a month is empty is the same defect with a narrower trigger.
- **`isRetrying` is real, not faked.** `useCalendarEvents` exposed no in-flight signal, so rather than pass a hardcoded `false` or reconstruct the query key with `useIsFetching`, the domain hook returns TanStack's `isRefetching` (additive; no consumer breaks). A retry button that never disables is a small lie in a phase about not telling small lies.
- **Fix the a11y defect, don't weaken the a11y spec.** `calendar-a11y` is red because it truthfully found violations in UI this change made reachable. Weakening it to green would be the forbidden shape.
- **`/events` cell-click behaviour preserved verbatim.** Clicking a day set the state that drove the month window (a no-op for an in-month day); after the rename it sets `currentMonth` to that day — identical semantics, zero new interaction invented.

#### Contrast computation (arithmetic, from resolved token values — tokens only, no raw hex in the CSS)

Method: sRGB → WCAG relative luminance (`c/12.92` below 0.03928, else `((c+0.055)/1.055)^2.4`;
`L = 0.2126R + 0.7152G + 0.0722B`), ratio `(L₁+0.05)/(L₂+0.05)`. Alpha compositing:
`out = α·fg + (1−α)·backdrop`, per channel. Token values read from
`frontend/src/design-system/tokens/directions.ts` (`PALETTES.linear`).

**Why the before-state failed.** `.cal-cell.other` sits inside `.cal-grid`, whose background is
`var(--line)`. `opacity: 0.4` composites the whole cell — its `--surface` background _and_ its
