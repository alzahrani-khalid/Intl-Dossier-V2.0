<objective>
Close the last NAV-01 surface. `/compare` currently offers seven entity types in three
independently maintained places — the route's `validateSearch` whitelist, the selector's option
list, and the selector's icon lookup — plus a per-type fetch arm and an extension-field registry in
the hook behind it. Widening one and not the others is the drift class; this plan moves them
together and sources the membership from the constant 97-04 established.

The substantive work is the fetch arm: `elected_official` is not a `dossiers.type` value, so the
EO arm queries persons filtered by `person_subtype` — no existing arm is subtype-filtered, which is
the one genuinely new shape in this plan. Its field configuration comes from the elected-officials
domain (office, term, party), not from a copy of the person arm's fields.

Purpose: the eighth type is selectable and the selection produces an honest result.
Output: one surface, five files, one new label key in two locales.
</objective>
