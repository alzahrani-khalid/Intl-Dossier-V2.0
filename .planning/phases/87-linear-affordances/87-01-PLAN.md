New store contract this plan defines (consumed by Wave-2 plans 87-06..87-09):

```typescript
export interface PeekRegistration {
  ids: string[]            // ordered ids of the loaded window
  type: string             // drawer type of the surface ('country' | ... | 'commitment')
  total: number            // FULL filtered count (not window length)
  pageOffset: number       // index of ids[0] within the full filtered list
  fetchPage?: (page: number) => Promise<string[]>  // neighbor loader; page is 1-based
  pageSize?: number        // needed to map index -> page for fetchPage (default 20)
}
export interface PeekState extends PeekRegistration { ... register, extendWindow, clear }
```
